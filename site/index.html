DFAM model

A component-level emulation of a Moog DFAM-style percussion synth. Two VCOs, noise, a ladder filter, envelopes and the 8-step sequencer, modelled block by block and running live in your browser.

About the model

  • Moog has not published DFAM schematics. Each block is modelled on the matching block of the published Werkstatt-01 schematic and the Moog-ladder modelling literature, then wired as the DFAM manual describes.
  • Component values are plausible estimates, not measurements, and every one of them is editable in the playground's Circuit panel.
  • The same engine exists as a header-only C++17 library with a WAV renderer, and as a JavaScript module that gives bit-identical output.

Read the README for build steps, patch keys and the list of open assumptions, or the circuit sources.
